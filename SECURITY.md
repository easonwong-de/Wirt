# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Wirt, please report it privately:

1. Navigate to the [Security Advisories tab](https://github.com/easonwong-de/wirt/security/advisories) on GitHub.
2. Select **Report a vulnerability**.
3. Provide a detailed summary, proof of concept, and affected environments.

Please do not disclose vulnerabilities in public issues or discussions before a fix has been released.
